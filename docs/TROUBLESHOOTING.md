# 安装与故障排查

## 双击 EXE 没有反应

完整解压 ZIP，检查系统是否为 64 位 Windows 10/11，并查看 Windows 安全中心的拦截记录。核对发行包 SHA256；不要从不明网盘取得修改版，也不要关闭安全软件。第一次解压单文件运行环境可能需要数秒。

## 找不到 MuMu / ADB 连接失败

运行 `LePaoRunner.exe --setup`，选择包含 `nx_main\MuMuManager.exe` 的安装目录。点“查询实例编号”，确认目标实例已经启动。助手和 App 必须针对同一个实例。重启模拟器后连接异常，可结束当前记录、关闭助手并重新打开。

## 点开始后不移动

按顺序核对：

1. 助手已勾选自动联动，并在 App 开始前显示随机起点已就绪。
2. 已通过 App 自身的权限提示、确认和倒计时，进入正式计时页面。
3. Android 位置开关开启，App 精确位置权限允许。助手等待的实际 GPS 点必须距准备起点小于 15 米。
4. 保持 App 跑步页在前台，勿停留在登录页、广告、设置或其他 App。
5. 使用适配的 4.2.6。该版暂停按钮自行绘制文字，普通无障碍读取可能为空，社区版用原生控件可见性识别；新版本页面结构变化需要更新代码。
6. 如果助手在记录开始后才启动，结束该条记录、返回首页重新准备。不要在记录中手动改定位。

## 位置跑到其他学校 / 草坪 / 跑道外

默认坐标是南宁学院示例，必须替换成你的跑道。核对纬经度顺序、坐标系和六点顺序。六点不是随便选的六个角，而是跑道两端顶点及四个直道相接点。

参考线会向内移约 0.1～1.85 米，所以要给草坪边缘留余量。边界模型近似，不能当作现场测绘。配准失败时先停止测试，重新校准后从首页准备。

## App 闪退

在已验证配置中使用 MuMu Android 12、DirectX 渲染、关闭 ROOT；可在实例设置中调整后重启。4.2.6 的 Android 15 兼容性不保证。只从官方渠道取得 App，不使用破解 APK。更改实例前先保存需要的数据。

## 轨迹看起来重叠 / 配速和助手日志不同

地图画线宽度与 App 的 GPS 平滑算法会改变显示效果；每圈坐标错开并不能保证屏幕线条分离。显示的平均配速也包含记录开始后等待 GPS 的时间，和当前目标配速不是同一个数值。

## 改完设置后不生效

路线在准备时生成。改变坐标或圈数后，先回乐跑首页等待重新准备。正在运行的记录不会被瞬间改成另一条路线。查看日志确认当前实例及准备状态。

## 报告问题

在 GitHub Issues 提供 Windows/MuMu/Android/App 版本、问题步骤及已去除个人信息的日志片段。不要上传密码、登录二维码、验证码、个人运动记录、完整配置目录或敏感截图。
